## With the CLI

Install the `riven-cli` archive for your platform (see [Installation](/docs/riven/getting-started/installation)), then:

```bash
riven install --side server --dir /srv/mc --headless gh:owner/pack
```

Only entries marked `server` or `both` and files from `overrides/common/` and `overrides/server/` are installed. Run the same command — or plain `riven install --dir /srv/mc --headless` — before every start to pick up new releases; an unchanged pack costs one small request.

::callout{type="info" title="The server core"}
  Riven installs the pack's mods and configs, not the loader itself. Install the NeoForge, Fabric or Forge server of the version in the pack's `riven.json` (`minecraft` and `loader`).
::

A systemd unit can update on every start:

```ini
[Service]
WorkingDirectory=/srv/mc
ExecStartPre=/usr/local/bin/riven install --headless
ExecStart=/srv/mc/run.sh
```

## With Nix

The flake's `lib.mkModpack` turns a pack repository into a store path with the server's mods and configs. Every file is its own `fetchurl` with the hash from `riven.json` — no `packHash`, no import-from-derivation, no riven binary at build time, and each mod is cached separately across versions.

```nix
{
  inputs.riven.url = "github:BX-Team/Riven";

  outputs = { nixpkgs, riven, ... }: {
    # …
    modpack = riven.lib.mkModpack {
      pkgs = nixpkgs.legacyPackages.x86_64-linux;
      src = ./.;                  # the pack repository
      side = "server";            # default
      groups.velocity = true;     # switch optional groups
      exclude = [ "easylogin" ];  # drop entries by id
    };
  };
}
```

| Argument | Default | Description |
| -------- | ------- | ----------- |
| `pkgs` | | nixpkgs to fetch with |
| `src` | | Folder holding `riven.json` and `overrides/` |
| `side` | `"server"` | `"server"` or `"client"` |
| `groups` | `{ }` | Group id → on/off; others use the pack's defaults |
| `exclude` | `[ ]` | Entry ids to leave out |

`riven.lib.readPack ./.` returns the parsed `riven.json`, handy for the loader version:

```nix
pack = riven.lib.readPack ./.;
# pack.minecraft, pack.loader.type, pack.loader.version
```

Keep secrets, ports and `server.properties` in your Nix module; ship only static server files in `overrides/server/`.
