## riven install

Installs a pack into a game folder, or updates the one installed there.

```bash
riven install gh:owner/pack                         # GitHub Pages of owner/pack
riven install https://example.com/pack/             # pack base URL
riven install https://example.com/pack/channels/beta.json
riven install ./MyPack.riven                        # archive
riven install                                       # update what is installed here
```

| Option | Description |
| ------ | ----------- |
| `--dir <path>` | Game folder; default the current directory |
| `--side <client\|server>` | Which side's files to install; default client |
| `--channel <name>` | Channel to follow; default `stable`, or the installed one |
| `--groups <list>` | Optional groups: `shaders,+minimap,-music` (`x`/`+x` on, `-x` off) |
| `--headless` | Never prompt and print no plan — for servers and scripts |
| `-y`, `--yes` | Apply without asking |

What an install does:

1. Fetches the channel pointer with `If-None-Match`; an unchanged pack ends here with one small request.
2. Verifies the signature and the manifest's sha512.
3. Plans against `.riven/state.json` and the disk: files to download, replace and remove.
4. Downloads into the shared store (parallel, retries, mirrors), checking every hash.
5. Swaps files in through a staging folder, then writes `.riven/state.json`.

Guarantees:

- Only files riven installed are ever removed — mods and worlds you added stay.
- Files the pack marks `preserve` (such as `options.txt`) are not overwritten once you changed them.
- An interrupted install leaves the previous state; running it again finishes the job.

The link, channel, side and groups are remembered, so `riven install` with no arguments updates.

### Signed packs

The pack's key is pinned on first install (trust on first use); after that, an unsigned release or a different key is refused. A link can also name the expected key up front: `https://example.com/pack/#key=ed25519:…`. See [Signatures and trust](/docs/riven/guides/signatures).

## riven status

```bash
riven status
riven status --dir /srv/mc --json
```

Shows the pack link, version, side, groups and file count of a game folder, whether it is signed, and whether the channel serves a newer release.

## riven trust

```bash
riven trust list
riven trust reset https://example.com/pack/channels/stable.json
```

`list` shows the keys pinned per pack; `reset` forgets one so the next install accepts a rotated key. The pins live in `<config>/trusted.json`.

## riven self-update

```bash
riven self-update --check   # only report
riven self-update
```

Downloads the newest Riven from GitHub Releases, verifies its sha256 and replaces the running copy. Copies installed by a package manager or Nix report that they are updated there instead.
