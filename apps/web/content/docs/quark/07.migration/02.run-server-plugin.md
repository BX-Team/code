title: Migrating from run-server-plugin
description: Move dev servers from org.bxteam.runserver to the Quark Gradle plugin.
---

`org.bxteam.runserver` moved into the Quark Gradle plugin. Version 2.0 of the old plugin only applies `org.bxteam.quark` and prints a warning:

```txt
The 'org.bxteam.runserver' plugin is deprecated and replaced by 'org.bxteam.quark':
configure dev servers in quark { devServer { ... } }.
```

The `tasks.runServer { }` DSL is gone. The task keeps its name, so IDE run configurations on `runServer` still work.

## Steps

::steps
:::step{title="Replace the plugin"}
The Quark plugin needs Shadow in the same project:

```kotlin
plugins {
    id("org.bxteam.runserver") version "1.2.2" // [!code --]
    id("com.gradleup.shadow") version "9.1.0" // [!code ++]
    id("org.bxteam.quark") version "2.0.0" // [!code ++]
}
```

You don't have to use any other Quark feature: without `platform`, `modules` and `quark(...)` dependencies no Quark code ends up in your jar, only an empty dependency manifest. The project needs a `group` though, Quark derives its relocation package from it.
:::

:::step{title="Move the configuration"}
Move the settings from `tasks.runServer { }` into `quark { devServer { } }`:

```kotlin
tasks { // [!code --]
    runServer { // [!code --]
        serverType(ServerType.PAPER) // [!code --]
        serverVersion("1.21.8") // [!code --]
        noGui(true) // [!code --]
        acceptMojangEula() // [!code --]
    } // [!code --]
} // [!code --]
quark { // [!code ++]
    devServer { // [!code ++]
        type = ServerType.PAPER // [!code ++]
        version = "1.21.8" // [!code ++]
        noGui() // [!code ++]
        acceptEula() // [!code ++]
    } // [!code ++]
} // [!code ++]
```

`ServerType` is now `org.bxteam.quark.gradle.ServerType`. If you set `quark { platform = ... }`, `type` can be left out.
:::

:::step{title="Run it"}
```bash
./gradlew runServer
```
:::
::

## DSL Mapping

| run-server-plugin | Quark |
|-------------------|-------|
| `serverType(ServerType.PAPER)` | `type = ServerType.PAPER` |
| `serverVersion("1.21.8")` | `version = "1.21.8"` |
| `allowedRam(4, RamAmount.GB)` | `ram(4, GB)` |
| `noGui(true)` | `noGui()` (on by default) |
| `acceptMojangEula()` | `acceptEula()` |
| `downloadPlugins { ... }` | `plugins { ... }` |
| `filePlugin(file)`, `filePlugin(file, overwrite = true)` | `file(file)`, `file(file, overwrite = true)` inside `plugins { }` |
| `filePlugins(a, b)` | `file(a)` and `file(b)` inside `plugins { }` |
| `serverFolderName("my-server")` | `runDirectory = layout.projectDirectory.dir("my-server")` |
| `serverFolder { ... }` | `runDirectory = ...` |
| `perVersionFolder(true)` | `perVersionFolder = true` |
| `inputTask(tasks.named("shadowJar"))` | `inputTask(...)`. The Shadow jar is the default |

Inside `plugins { }` the sources are the same: `modrinth`, `hangar`, `github`, `jenkins` and `url`.

## New in Quark

- **Pinned builds**: `build(196)` keeps the server on one build, `"latest"` checks for new builds on every run.
- **Offline runs**: without network access the cached server jar is used.
- **Java toolchains**: the server runs on the Java its Minecraft version needs, not on the Java Gradle runs on.
- **Several servers**: `devServers { register("proxy") { ... } }` adds `runProxyServer` next to `runServer`.
- **Folia**: `ServerType.FOLIA` is supported.

Read [Dev Servers](/docs/quark/gradle-plugin/dev-servers) for everything else.
