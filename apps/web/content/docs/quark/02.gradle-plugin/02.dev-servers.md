A dev server is a real server started by Gradle with your plugin already installed. It downloads the server jar from [MCJars](https://mcjars.app), copies the Shadow jar into `plugins/`, installs other plugins you list and runs in your terminal, so you can type console commands.

::callout{type="info"}
  Dev servers replace the standalone `org.bxteam.runserver` plugin. If you used it, read [Migrating from run-server-plugin](/docs/quark/migration/run-server-plugin).
::

## Basic

::code-group
```kotlin [Gradle Kotlin]
quark {
    platform = ServerPlatform.PAPER

    devServer {
        version = "1.21.8"
        acceptEula()
    }
}
```
```groovy [Gradle Groovy]
quark {
    platform 'paper'

    devServer {
        version = '1.21.8'
        acceptEula()
    }
}
```
::

Then start it:

```bash
./gradlew runServer
```

The server runs in `run/paper`. Stop it with `stop` in the console or `Ctrl+C`.

## Advanced

```kotlin
import org.bxteam.quark.gradle.ServerType

quark {
    devServer {
        // server software, defaults to the type of quark.platform
        type = ServerType.PURPUR
        version = "1.21.8"

        // "latest" (default) or a pinned build number
        build(2470)

        // heap size, 2 GB by default
        ram(4, GB)

        // Java version, defaults to what the Minecraft version needs
        javaVersion = 21

        acceptEula()
        noGui()

        // run/<version>/<type> instead of run/<type>
        perVersionFolder = true
        // or a fixed directory
        runDirectory = layout.projectDirectory.dir("servers/test")

        // install another jar instead of the Shadow jar
        inputTask(tasks.named<Jar>("jar"))

        plugins {
            modrinth("worldedit", "7.3.12")
            hangar("squaremap", "1.3.5")
            github("NEZNAMY", "TAB", "5.2.0", "TAB.v5.2.0.jar")
            jenkins("https://ci.athion.net", "FastAsyncWorldEdit", Regex("Bukkit"))
            url("https://download.luckperms.net/1581/bukkit/loader/LuckPerms-Bukkit-5.4.164.jar")
            file(file("libs/my-other-plugin.jar"))
            file(file("libs/always-fresh.jar"), overwrite = true)
        }
    }
}
```

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `version` | required | Minecraft version, or the proxy version for Velocity and BungeeCord (`"3.4.0-SNAPSHOT"`) |
| `type` | from `quark.platform` | Server software, see [Server Types](#server-types) |
| `build` | `"latest"` | `"latest"` checks MCJars on every run and downloads new builds; a number pins the build |
| `ram(amount, unit)` / `maxMemory` | `2G` | Maximum heap, `ram(4, GB)` or `maxMemory = "4G"` |
| `javaVersion` | from `version` | Java the server runs on, taken from your [Java toolchains](https://docs.gradle.org/current/userguide/toolchains.html) |
| `acceptEula()` | `false` | Accepts the [Mojang EULA](https://aka.ms/MinecraftEULA) for you |
| `noGui()` | `true` | Disables the server GUI (Minecraft 1.15.2 and newer) |
| `runDirectory` | `run/<type>` | Directory the server runs in |
| `perVersionFolder` | `false` | Uses `run/<version>/<type>` for the default server |
| `inputTask(task)` / `inputJar` | Shadow jar | The plugin jar copied into `plugins/` |
| `plugins { }` | none | Other plugins installed next to yours |

Without network access the newest cached build of the version is used, so you can work offline once the server was downloaded.

### Java Version

Unless you set `javaVersion`, Quark picks it from the Minecraft version:

| Minecraft | Java |
|-----------|------|
| `26` and newer | 25 |
| `1.20.5` - `1.21.x` | 21 |
| `1.17` - `1.20.4` | 17 |
| older | 8 |
| Velocity, BungeeCord | 21 |

Gradle provides that Java through toolchains, downloading it if a toolchain resolver is configured. If MCJars says the build needs a newer Java, the task stops and tells you which `javaVersion` to set.

## Plugins

Every entry of `plugins { }` is downloaded when the task runs, never while Gradle configures the build.

| Source | Example | Notes |
|--------|---------|-------|
| `modrinth(project, version)` | `modrinth("worldedit", "7.3.12")` | Picks the file for the server's loader, fails if the version does not support it |
| `hangar(project, version)` | `hangar("squaremap", "1.3.5")` | Picks the download for the server's platform |
| `github(owner, repo, tag, file)` | `github("NEZNAMY", "TAB", "5.2.0", "TAB.v5.2.0.jar")` | An asset of a GitHub release |
| `jenkins(url, job, pattern)` | `jenkins("https://ci.athion.net", "FastAsyncWorldEdit", Regex("Bukkit"))` | First artifact of the last successful build whose path matches |
| `url(url)` | `url("https://example.com/plugin.jar")` | A direct download |
| `file(file, overwrite)` | `file(file("libs/plugin.jar"))` | A local jar, copied unless it exists and `overwrite` is `false` |

Forks use the loader of the server they are based on: a Purpur or DivineMC server accepts Paper, Spigot and Bukkit plugins from Modrinth.

## Multiple Servers

`devServer { }` configures the server named `default`, run by `runServer`. Every other entry of `devServers { }` gets a `run<Name>Server` task and runs in `run/<name>`:

::code-group
```kotlin [Gradle Kotlin]
import org.bxteam.quark.gradle.ServerPlatform
import org.bxteam.quark.gradle.ServerType

quark {
    platform = ServerPlatform.PAPER

    devServer {
        version = "1.21.8"
        acceptEula()
    }

    devServers {
        register("folia") {
            type = ServerType.FOLIA
            version = "1.21.8"
            acceptEula()
        }
        register("legacy") {
            version = "1.20.4"
            acceptEula()
        }
    }
}
```
```groovy [Gradle Groovy]
import org.bxteam.quark.gradle.ServerType

quark {
    platform 'paper'

    devServer {
        version = '1.21.8'
        acceptEula()
    }

    devServers {
        register('folia') {
            type = ServerType.FOLIA
            version = '1.21.8'
            acceptEula()
        }
        register('legacy') {
            version = '1.20.4'
            acceptEula()
        }
    }
}
```
::

This registers `runServer`, `runFoliaServer` and `runLegacyServer`.

## Server Types

| `ServerType` | Plugins it accepts |
|--------------|--------------------|
| `PAPER`, `PUFFERFISH`, `PURPUR`, `DIVINEMC`, `LEAF`, `LEAVES` | Paper, Spigot and Bukkit |
| `FOLIA`, `CANVAS` | Folia, plus Paper, Spigot and Bukkit |
| `SPIGOT` | Spigot and Bukkit |
| `VELOCITY`, `VELOCITY_CTD` | Velocity |
| `BUNGEECORD`, `WATERFALL` | BungeeCord |

The default type comes from `quark.platform`: `PAPER` → Paper, `FOLIA` → Folia, `BUKKIT` → Spigot, `VELOCITY` → Velocity, `BUNGEE` → BungeeCord.

## Runtime Dependencies

Before the server starts, the task copies the `quark` dependencies Gradle already downloaded into the plugin's library folder (`plugins/<YourPlugin>/libs`). `loadFromGradle()` finds them there, so the dev server starts without downloading your libraries again.

::callout{type="tip"}
  Add `run/` to your `.gitignore`. Server jars are cached once per Gradle user home (`~/.gradle/caches/quark/dev-servers`), not per project.
::
