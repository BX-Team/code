Every Quark module logs through `QuarkLogger`, a small facade over the logger the server already gives your plugin: `java.util.logging` on Bukkit and BungeeCord, SLF4J on Velocity. `platform.logger()` returns the plugin's logger in this form.

## QuarkLogger

```java
QuarkLogger logger = platform.logger();

logger.info("Loaded {} homes for {}", homes.size(), player.getName());
logger.warn("Unknown world '{}', using the default", worldName);
logger.error("Could not save data", exception);

// the message is only built when debug output is on
logger.debug(() -> "Cache state: " + cache.dump());

// prepends [Database] to every message
QuarkLogger databaseLogger = logger.prefixed("Database");
```

`{}` placeholders are replaced by the arguments in order. Pass a `QuarkLogger` to Quark's modules (`LibraryManager.builder().logger(...)`, `options.logger(...)`, `checker.checkAndLog(...)`) to get their messages under your plugin's name.

## Implementations

| Class | Module | Wraps |
|-------|--------|-------|
| `JulLogger` | `quark-common` | `java.util.logging.Logger`, the default everywhere |
| `Slf4jLogger` | `quark-logger` | `org.slf4j.Logger` |
| `Log4jLogger` | `quark-logger` | `org.apache.logging.log4j.Logger` |

```java
QuarkLogger jul = new JulLogger(getLogger());
QuarkLogger slf4j = new Slf4jLogger(LoggerFactory.getLogger("MyPlugin"));
QuarkLogger standalone = JulLogger.of("MyPlugin");
```

`quark-logger` is added with `quark { modules(QuarkModule.LOGGER) }`. The Velocity adapter brings it along, the SLF4J and Log4j APIs themselves come from the server.

## Debug Switch

Server loggers usually drop debug messages, so a `debug: true` option in your config does nothing on its own. `DebugSwitch` fixes that: loggers wrapped with it print debug messages at info level with a `[DEBUG]` prefix while the switch is on.

```java
QuarkLogger logger = DebugSwitch.wrap(platform.logger());

// e.g. after loading the config
DebugSwitch.setEnabled(config.debug);

logger.debug(() -> "Player " + player.getName() + " opened the menu");
// [MyPlugin] [DEBUG] Player Steve opened the menu
```

While the switch is off, debug messages go to the logger's own debug level as usual. Quark is relocated into every plugin, so the switch only affects your plugin.
