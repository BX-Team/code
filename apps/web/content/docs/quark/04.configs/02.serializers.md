A serializer turns a value into a node of the file and back. Quark brings serializers for the JDK types you usually need, for Bukkit types on Bukkit-based servers, and binds any other class field by field.

## Standard Types

| Type | In the file |
|------|-------------|
| `String`, `char` | `text`, `x` |
| `boolean`, `int`, `long`, `double`, `float`, `short`, `byte` and their wrappers | `true`, `42`, `0.5`. Numbers must fit the type |
| `BigInteger`, `BigDecimal` | `12345678901234567890` |
| Enums | `CREATIVE`. Reading ignores case and accepts `-` and spaces for `_` |
| `UUID` | `7c0b0d6c-0f4e-4a3e-9b8a-6d3c5f0e2a11` |
| `Duration` | `30s`, `5m`, `1h30m`, `500ms`, `2d` or ISO-8601 (`PT1H30M`). A bare number is seconds |
| `Instant` | `2025-01-31T12:00:00Z`, or epoch milliseconds |
| `Optional<T>` | The value, or `null` for `Optional.empty()` |
| `List`, `Set`, `Collection`, arrays, `EnumSet` | YAML lists |
| `Map<K, V>` | YAML sections. Keys are converted like any other value |
| `ConfigNode` | Any subtree, as it is |
| `Object` | Plain maps, lists and scalars |
| Records, classes with a no-argument constructor | Sections, field by field |

```java
public class ShopConfig extends QuarkConfig {
    public Duration restockInterval = Duration.ofHours(1);
    public Map<String, Integer> prices = Map.of("diamond", 100, "emerald", 50);
    public List<Reward> rewards = List.of(new Reward("gold_ingot", 16));
    public Optional<UUID> owner = Optional.empty();

    public record Reward(String item, int amount) {
    }
}
```

```yaml
restock-interval: 1h
prices:
  diamond: 100
  emerald: 50
rewards:
- item: gold_ingot
  amount: 16
owner: null
```

Nested classes and records follow the [naming strategy](/docs/quark/configs/creating-configs#naming-styles) of their config and may use `@Comment`, `@CustomKey` and `@Exclude` on their fields.

## Bukkit Types

On Paper, Folia and Bukkit the Gradle plugin adds `quark-config-serdes-bukkit` together with the config module. It registers itself, nothing to configure.

| Type | In the file |
|------|-------------|
| `ItemStack` | The same format as Bukkit's own YAML configuration |
| Any `ConfigurationSerializable` | `ItemMeta`, `Color`, `Vector`, `PotionEffect`, ... in Bukkit's format. Nested values carry their `==` alias, like in Bukkit's YAML |
| `Location` | A section with `world`, `x`, `y`, `z`, `yaw`, `pitch` |
| `Sound` | Its key, `entity.player.levelup`. Enum names (`ENTITY_PLAYER_LEVELUP`) are accepted too |
| Adventure `Component` | A [MiniMessage](https://docs.advntr.dev/minimessage/) string, on servers with MiniMessage (Paper) |

```java
public class LobbyConfig extends QuarkConfig {
    public Location spawn = new Location(null, 0.5, 64, 0.5);
    public Sound joinSound = Sound.ENTITY_PLAYER_LEVELUP;
    public Component welcome = MiniMessage.miniMessage().deserialize("<green>Welcome!</green>");
    public ItemStack compass = new ItemStack(Material.COMPASS);
}
```

```yaml
spawn:
  x: 0.5
  y: 64.0
  z: 0.5
  yaw: 0.0
  pitch: 0.0
join-sound: entity.player.levelup
welcome: <green>Welcome!</green>
compass:
  type: COMPASS
  # ... the other keys Bukkit writes for this item
```

::callout{type="warn" title="Locations need loaded worlds"}
  A `Location` with a world can only be read when that world is loaded. Load such configs in `onEnable()`, not in `onLoad()`, or store the world name as a `String` and resolve it later.
::

## Custom Serializers

For a type Quark can't bind field by field, write a `TypeSerializer` and register it in the options:

```java
config = QuarkConfig.create(PluginConfig.class, options -> options
        .file(folder.resolve("config.yml"))
        .serdes(registry -> registry
                .register(NamespacedKey.class, TypeSerializer.ofString(NamespacedKey::fromString, NamespacedKey::asString))
                .register(Cuboid.class, new CuboidSerializer())));
```

### Single-String Types

Most custom types are stored as one string. `TypeSerializer.ofString(parse, format)` covers them. When `parse` throws `IllegalArgumentException` or returns `null`, the load fails with a message naming the key.

### Full Serializers

Implement `TypeSerializer<T>` when the type is a section. Nested values go through the `SerdesContext`, so they use every registered serializer:

```java
public final class CuboidSerializer implements TypeSerializer<Cuboid> {
    @Override
    public Cuboid deserialize(Type type, ConfigNode node, SerdesContext context) {
        String world = node.node("world").getString();
        if (world == null) {
            throw new SerializationException("missing world");
        }
        Vector min = context.deserialize(node.node("min"), Vector.class);
        Vector max = context.deserialize(node.node("max"), Vector.class);
        return new Cuboid(world, min, max);
    }

    @Override
    public void serialize(Type type, Cuboid value, ConfigNode node, SerdesContext context) {
        node.node("world").set(value.world());
        context.serialize(value.min(), Vector.class, node.node("min"));
        context.serialize(value.max(), Vector.class, node.node("max"));
    }
}
```

Serializers never see `null`: missing and null nodes become `emptyValue(type)` (`null` unless you override it), and null values are written as `null`. Throw `SerializationException` with a short reason, Quark adds the file and the key.

### Registration Methods

| Method | Matches |
|--------|---------|
| `register(Class, serializer)` | Exactly this class (and its primitive for wrappers) |
| `registerHierarchy(Class, serializer)` | This class and all its subtypes |
| `register(Predicate<Type>, serializer)` | Any type the predicate accepts |
| `register(SerdesPack)` | All serializers of a pack |

The newest registration wins, so you can replace a standard serializer, for example store `Duration` as seconds.

## Serializer Packs

A `SerdesPack` groups serializers. Pass it to `options.serdes(...)`, or let every config pick it up by registering it as a service in `META-INF/services/org.bxteam.quark.config.serdes.SerdesPack`:

```java
public final class MyTypes implements SerdesPack {
    @Override
    public void register(SerdesRegistry registry) {
        registry.register(Rank.class, TypeSerializer.ofString(Rank::valueOf, Rank::name));
    }
}
```

```txt [META-INF/services/org.bxteam.quark.config.serdes.SerdesPack]
com.example.config.MyTypes
```

This is how `quark-config-serdes-bukkit` registers itself. Packs passed in the options win over discovered ones.
