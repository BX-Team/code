Every build is attached to the [latest GitHub release](https://github.com/BX-Team/Riven/releases/latest).

## Desktop

| System | File |
| ------ | ---- |
| Windows (x86_64) | `Riven-Setup-x86_64.exe` (installer, no admin rights) or `riven-x86_64-windows.zip` (portable) |
| macOS 11+ (Apple silicon and Intel) | `Riven-macos.dmg` |
| Linux, any distribution | `Riven-x86_64.AppImage` / `Riven-aarch64.AppImage` |
| Debian / Ubuntu | `riven_<version>_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `riven-<version>-1.x86_64.rpm` / `.aarch64.rpm` |
| Arch | `riven-<version>-1-x86_64.pkg.tar.zst` |

::callout{type="warning" title="macOS"}
  The app is not notarized. Right-click Riven Launcher → **Open** the first time.
::

The installer, the packages and the AppImage register `riven://` links and the `.riven` file type, so install links from a website open in the launcher.

## Server (CLI only)

The `riven-cli-<arch>-<os>` archives contain the same `riven` binary without the GUI and its system libraries:

```bash
curl -L -o riven-cli.tar.gz \
  https://github.com/BX-Team/Riven/releases/latest/download/riven-cli-x86_64-linux.tar.gz
tar -xzf riven-cli.tar.gz
./riven --version
```

## Nix

```bash
nix run github:BX-Team/Riven            # the launcher
nix run github:BX-Team/Riven#riven-cli  # the CLI alone
```

See [Servers](/docs/riven/guides/servers) for building a pack in Nix.

## Updating

The launcher updates itself from GitHub Releases (**Settings → About**); the CLI does it with [`riven self-update`](/docs/riven/cli/installing#riven-self-update). Copies installed by a package manager or Nix are updated there instead.
