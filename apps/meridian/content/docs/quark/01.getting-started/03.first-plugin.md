This page builds a small plugin that downloads a library at startup, reads a config and checks for updates. Pick your platform in the code blocks below, the rest stays the same.

## Build Script

::code-group
```kotlin [Paper]
import org.bxteam.quark.gradle.QuarkModule
import org.bxteam.quark.gradle.ServerPlatform

plugins {
    java
    id("com.gradleup.shadow") version "9.1.0"
    id("org.bxteam.quark") version "2.0.0"
}

group = "com.example"
version = "1.0.0"

repositories {
    mavenCentral()
    maven("https://repo.papermc.io/repository/maven-public/")
}

dependencies {
    compileOnly("io.papermc.paper:paper-api:1.21.8-R0.1-SNAPSHOT")
    quark("com.zaxxer:HikariCP:7.1.0")
}

quark {
    platform = ServerPlatform.PAPER
    modules(QuarkModule.DEPENDENCY, QuarkModule.CONFIG, QuarkModule.CONFIG_VALIDATOR, QuarkModule.UPDATE)

    pluginYml {
        name = "Example"
        main = "com.example.ExamplePlugin"
        apiVersion = "1.21"
    }

    devServer {
        version = "1.21.8"
        acceptEula()
    }
}

java {
    toolchain.languageVersion = JavaLanguageVersion.of(21)
}
```

On Paper `pluginYml { }` writes the `plugin.yml`, see [Plugin Descriptor](/docs/quark/gradle-plugin/plugin-yml). On Velocity the annotation processor writes `velocity-plugin.json` from `@Plugin`.

## Config Class

A config is a plain class. Field initializers are the defaults, the annotations become comments and checks:

```java
@Header("Example plugin configuration")
@NameStrategy(NameStyle.HYPHEN_CASE)
public class PluginConfig extends QuarkConfig {
    @Comment("Prefix of every message")
    public String prefix = "<gray>[Example]</gray> ";

    @Comment("How often the cache is cleared")
    public Duration cacheTime = Duration.ofMinutes(5);

    public Database database = new Database();

    public static class Database {
        public String host = "localhost";

        @Min(1) @Max(65535)
        public int port = 3306;
    }
}
```

## Main Class

Load dependencies as early as possible, before any class that uses them is touched. The config and the update check come after that.

::code-group
```java [Paper]
public final class ExamplePlugin extends JavaPlugin {
    private PluginConfig config;

    @Override
    public void onLoad() {
        LibraryManager.builder()
                .plugin(this)
                .dataDirectory(getDataFolder().toPath())
                .build()
                .loadFromGradle();
    }

    @Override
    public void onEnable() {
        Platform platform = PaperPlatform.create(this);

        config = QuarkConfig.create(PluginConfig.class, getDataFolder().toPath().resolve("config.yml"));
        config.load();

        UpdateChecker checker = new UpdateChecker(UpdateProvider.modrinth("example"), getPluginMeta().getVersion());
        checker.checkAndLog(platform.logger());
        BukkitUpdateNotifier.register(this, checker, "example.update");
    }
}
```
```java [Velocity]
@Plugin(id = "example", name = "Example", version = "1.0.0")
public final class ExamplePlugin {
    private final ProxyServer server;
    private final Path dataDirectory;
    private PluginConfig config;

    @Inject
    public ExamplePlugin(ProxyServer server, @DataDirectory Path dataDirectory) {
        this.server = server;
        this.dataDirectory = dataDirectory;

        LibraryManager.builder()
                .plugin(this)
                .dataDirectory(dataDirectory)
                .build()
                .loadFromGradle();
    }

    @Subscribe
    public void onProxyInitialize(ProxyInitializeEvent event) {
        Platform platform = VelocityPlatform.create(server, this, dataDirectory);

        config = QuarkConfig.create(PluginConfig.class, dataDirectory.resolve("config.yml"));
        config.load();

        UpdateChecker checker = new UpdateChecker(UpdateProvider.modrinth("example"), "1.0.0");
        checker.checkAndLog(platform.logger());
        VelocityUpdateNotifier.register(server, this, checker, "example.update");
    }
}
```
::

## Run It

```bash
./gradlew runServer
```

The task builds the shaded jar, downloads the server, copies the plugin into `run/paper/plugins` (or `run/velocity/plugins`) and starts it in your terminal. On the first start the plugin writes `config.yml`:

```yaml [config.yml]
# Example plugin configuration

# Prefix of every message
prefix: '<gray>[Example]</gray> '
# How often the cache is cleared
cache-time: 5m
database:
  host: localhost
  port: 3306
```
