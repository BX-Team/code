Quark supports multiple platforms. You can find all of them in the table below.

| Platform Name                             | Compatible with                  | Compatible version        |
|-------------------------------------------|----------------------------------|---------------------------|
| `bukkit`                                  | Bukkit / Spigot / Paper / Purpur | `1.8.8` - `1.21.10`       |
| `bungeecord`                              | BungeeCord / Waterfall           | `1.19-R0.1` - `1.21-R0.4` |
| `fabric`                                  | Fabric                           | `Fabric Loader 0.14.25+`  |
| `paper`                                   | Paper / Purpur / other forks     | `1.19.3` - `1.21.10`      |
| `sponge`                                  | SpongeVanilla / SpongeForge      | `1.16.5+`                 |
| `velocity`                                | Velocity                         | `3.1.1+`                  |

::callout{type="info" title="How to use it?"}
  To use Quark with a specific platform, you need to add the platform dependency to your project. See the [Installing](/docs/quark/getting-started/installation) page for more information.
::
